# 日历任务弹框切换与验收记录

日期：2026-10-24。分支：`experiment/macos-native`。

## 交互规则与核心修改

- 点击另一条任务：一次点击更新详情及位置锚点，选中项直接从 A 切到 B，不先清空。
- 点击空白：关闭详情并消费点击，避免顺带触发时间网格新建。
- 点击当前任务或详情内部：保持详情打开，内部编辑按原规则工作。
- 原因有两处：透明关闭遮罩吃掉任务点击；`openTask` 的 `editingTaskID == nil` 守卫拒绝已打开时的切换。
- 当前源码已将守卫改为 `editingTaskID != id`；任务条上报布局锚点，关闭遮罩为任务范围留出命中区域。任务切换继续使用共享详情与原有文档切换保存机制。
- 时间条的锚点探针放在位移之前，使上报的位置与显示位置一致。

# 打勾 macOS 滴答清单交互对齐改造方案

日期：2026-09-14  
目标分支：`feature/flutter-personal-desktop`  
范围：`desktop/` 的 Flutter macOS 个人版，不涉及 Web、后端、账号、协作或同步。

## 1. 本轮判断

这不是单纯的颜色或圆角问题。当前版本已经具备任务、笔记、自然语言录入、统计、看板和
习惯等能力，但与本地滴答清单实际使用相比，主要差距集中在“任务列表是主工作区”这件事：

| 观察到的差异 | 当前行为 | 影响 | 优先级 |
| --- | --- | --- | --- |
| 任务列表比例 | 侧栏和列表偏宽，详情被挤到右侧 | 首屏可见任务较少，扫描效率低 | P0 |
| 添加任务 | 列表页默认显示大卡片 | 与滴答的单行快速录入不一致 | P0 |
| 列表行 | 舒适模式仍是带卡片边框的分组 | 长清单视觉噪声较大 | P0 |
| 智能清单 | 缺少“最近 7 天”和独立“过期”入口 | 用户需要通过“计划/今天”推断范围 | P1 |
| 列表页工具栏 | 只有页面标题和全局工具 | 排序、隐藏已完成等常用操作不在手边 | P1 |
| 任务右键菜单 | 只有完成、日期、副本、删除 | 日期清除、明天、优先级快捷操作缺失 | P1 |
| 键盘操作 | Enter/Space 可用，列表上下移动不足 | macOS 键盘工作流不完整 | P1 |
| 侧栏组织 | 标签始终展开，位置区偏长 | 与滴答的分组折叠语法不一致 | P2 |
| 原生菜单 | 只有“文件/编辑/视图” | 缺少滴答式“清单/任务”菜单 | P2 |

判断边界：滴答清单的账号、协作、云同步、社交、模板市场不属于本地个人版目标；本轮只借鉴
其已经稳定的导航语法、列表密度和任务操作路径。

## 2. 设计目标

1. 任务列表成为第一视觉层：侧栏窄、列表可扫描、详情按需出现。
2. 一行完成大多数任务操作：输入、日期、优先级、清单、标签和完成状态都能就地处理。
3. 所有新增入口复用现有 `WorkspaceController`，不在视图层复制任务状态。
4. 交互反馈不改变布局尺寸：选中、悬停、拖拽和焦点只改变颜色/透明度/边框。
5. 默认尺寸适配 1280×820；窗口缩小时保留单列详情回退，不牺牲可编辑性。

## 3. 实施计划

### P0：列表主工作区（本轮必须完成）

- 将 macOS shell 调整为约 52pt 图标栏 + 190pt 导航栏；任务列表在宽窗约占 32%，详情占剩余空间。
- 详情在宽窗默认常驻，空状态也保留编辑栏；设置仍提供“宽窗常驻详情”开关，允许个人工作流改回列表优先。
- 任务列表左对齐，不再为了 `maxWidth` 在内容区居中留出额外空白。
- 列表页快速录入固定使用滴答式单行样式；获得焦点后再展开解析摘要和属性操作。
- 列表分组改为扁平行 + hairline 分隔，保留“已过期/今天/已完成”等分组标题。
- 行标题在紧凑列表中单行省略，描述和元数据保留第二层信息。

### P1：高频操作补齐

- 新增“最近 7 天”和“过期”智能清单，日期范围由任务 `dueAt` 实时推导。
- 列表标题右侧增加排序菜单（手动/日期/优先级）和列表操作菜单（展开/收起已完成）。
- 任务右键/更多菜单增加：清除日期、安排到明天、设置优先级。
- 任务行获得焦点后支持 ↑/↓ 选择相邻任务，详情和列表选择保持同步；详情按 Escape 收起。
- 原生 macOS 菜单增加“清单”和“任务”两组常用入口，并复用 Dart 控制器行为。

### P2：细节收口

- 标签区支持折叠并在当前运行期保持状态；位置区只放视图入口。
- 清单、标签、任务和详情按钮统一 32–36pt 命中区域、12–14pt 文字层级。
- 对首页、日历、看板、矩阵使用同一组列表色和空态，不引入新的业务状态。

## 4. 验收标准

### 自动化验收

1. `flutter test` 全部通过，并新增以下断言：
   - 最近 7 天/过期投影只包含符合日期范围的未完成任务；
   - 列表排序菜单改变可见任务顺序；
   - 快速录入在列表页使用单行样式；
   - ↑/↓ 选择相邻任务，Escape 收起详情；
   - 详情与列表在 1280×820 下没有溢出。
2. `dart analyze` 无新增 error/warning。
3. `flutter build macos --release` 成功。
4. `git diff --check` 通过。

### 可执行界面验收

1. 启动 Release 应用，默认窗口约 1280×820；侧栏、列表、详情比例符合本方案。
2. 在今天页输入 `明早9点 #工作 @个人 !!!准备评审`，Return 后任务立即出现在列表，解析摘要可见。
3. 对任务右键，分别执行“明天”“清除日期”“高优先级”，列表和详情同步更新。
4. 选择任务后按 ↑/↓，选择框和详情跟随移动；按 Escape 收起详情。
5. 切换“最近 7 天”和“过期”，任务范围与日期真实数据一致。
6. 打开“紧凑密度”和“详情常驻”偏好，重启后仍保留；窄窗仍能返回详情。
7. 原生菜单可打开清单/任务入口；快捷键、系统通知和菜单栏快速录入继续沿用上一轮实机验收清单。

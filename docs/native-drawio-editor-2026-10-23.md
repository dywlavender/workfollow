# 原生编辑器接入 draw.io

日期：2026-10-23。分支：`experiment/macos-native`。

## 使用方式

- 笔记、任务正文格式工具栏增加「流程图（draw.io）」；窄栏可从工具栏的「更多」进入。
- 正文输入 `/`，在菜单里选择「流程图（draw.io）」。沿用任务与笔记现有的斜杠菜单交互。
- 在绘图窗口编辑图形、连线、文字、布局与多页图表，点击「保存并关闭」插入正文。
- 正文显示图表预览与名称，双击预览继续编辑。普通文字输入、删除、撤销与重做仍由原生编辑器处理。
- 「导入…」读取 `.drawio` / XML；「导出 .drawio…」导出可继续编辑的图源。
- WorkFollow 内复制、剪切、粘贴图表会保留图源；粘贴副本使用新的图表标识。复制到纯文本应用显示图表名称。

## 接入方案与边界

采用实际 draw.io 引擎，绘图窗口通过 WKWebView 承载；任务和笔记的正文继续使用现有原生编辑器。界面为中文，可调整窗口大小，头部保留图表名称、导入、导出、取消、保存并关闭。

`NativeDiagram` 保存图表标识、名称、XML 与 PNG 预览，作为 `DocumentRun.diagram` 的可选字段。图源和预览随正文一同进入现有 SQLite 文档存储与撤销记录，不需要另外管理可失联的临时图源文件。旧文档缺少该字段时保持兼容。

资源来自同工作区网页版的 `frontend/public/drawio`，所带运行引擎版本为 31.4.5。原有资源文件不改写，保留版权与目录许可证，并补入上游 Apache 2.0 许可证。打包脚本为 `macos-native/scripts/package-drawio.py`，资源归档约 34.6 MiB。资源是正式功能依赖，归档避免将数千个文件直接铺入原生工程。

首次使用在后台解压到 `~/Library/Caches/WorkFollow/Drawio/1/`；后续复用。通过 `workfollow-drawio://editor/` 为 WebKit 提供本地资源，无须启动本地服务器。绘图窗口拦截 HTTP/HTTPS 资源请求，普通绘图和预览导出均离线完成。云盘、外部网络图片与在线服务不属于本轮接入范围。

与 draw.io 的通信遵循[官方嵌入协议](https://www.drawio.com/docs/reference/embed-mode/)，使用 configure / load / autosave / export 消息；归档携带[上游许可证](https://github.com/jgraph/drawio/blob/dev/LICENSE)。未保存的修改只在绘图窗口内保留；取消不插入图表，已有修改退出时由原生对话框确认。

完整任务详情验收使用临时数据和生产 `TaskInspectorShell`，不是直接调用绘图回调模拟成功。实际绘图引擎通过本地协议初始化，生成图源与 PNG；预览分辨率另有断言，并已查看绘图画布与窄任务栏的渲染结果。

实施中修正了两处真实问题：

1. `file://` 子框架未完成绘图初始化，改为 WebKit 自定义本地协议。
2. 手动注册图表替换撤销会与 TextKit 的撤销冲突，改为现有富文本插入路径，图源与预览作为同一个原生文本附件撤销。

另修正了预览清晰度：draw.io 的 `width` 导出参数会限制小图放大，改为按模型边界计算导出比例，生成适合 Retina 正文预览的图片。

## 2026-10-23：连续保存重复插入修复

问题已通过真实 draw.io 引擎和生产 `TaskInspectorShell` 复现：新建图表窗口不关闭，调用引擎自身的保存动作三次，正文图表依次增加到三份，最后「保存并关闭」增加到四份。同一张图使用同一个图表标识。

根因是首次新建时宿主回调捕获的 `diagram` 为 nil，窗口内后续保存仍传 `existingID: nil`；正文保存函数据此反复在原始位置插入，没有根据本次图表自身的标识定位已保存附件。原验收覆盖单次「保存并关闭」和关闭后重新打开，漏掉了同一窗口内的连续保存。

修复以图表标识作为定位依据，首次插入后再次保存更新同一附件。完全未改变的保存直接成功返回，不额外创建撤销步骤。窗口回调不再依靠最初是否为新图来判断后续保存的插入或更新。

已有同标识重复副本在下一次明确保存该图时合并，使用当前绘图窗口导出的版本；中间文字和不同标识的独立图表保留。合并作为一次原生文本替换，撤销可以恢复先前的全部版本。没有直接改写用户库或按外观删除相似图表。

富文本替换使用 NSTextView 的 `shouldChangeText` 登记原生撤销，再精确替换属性并发布变更，避免批量合并时 `insertText` 将旧图表属性继承到中间的普通文字。

# 滴答复刻后续收敛：常用专注与日历直接操作

分支：`experiment/macos-native`。参考：本机滴答 macOS 8.0.80。延续[前轮实施验收](ticktick-replica-implementation-2026-10-14.md)，本轮继续核对普通可见流程。

## 参考客户端实测

常用专注库左侧为“番茄专注”，有“坚持中 / 已归档”。点击普通行，只在右侧查看该项详情，不开始专注、不改底部默认时长；点击行尾播放才立即开始并展开计时页。详情包含专注天数、今日时长、总时长、周/月图及该项记录。底部紧凑计时条可以展开，计时页左上向下箭头返回库。

活动项菜单有编辑、添加记录、归档和删除。归档前提示“归档后将无法进行专注，是否确认归档？”。归档页仍能打开历史详情，行内隐藏时长和播放，菜单为恢复和删除。

证据：[库与详情](audits/ticktick-replica-2026-10-15/reference-presets-detail.png)、[归档状态](audits/ticktick-replica-2026-10-15/reference-presets-archived.png)，对应 JSON 只保存选定的原生控件字段。截图与操作分别由 REA 和 CUA 完成。

短结束又确认了两个实际结果：同一10分钟常用项，14有效秒暂停后立即结束直接返回库，不留记录；57有效秒暂停、等待后结束出现“提前放弃专注？本次专注不足5分钟，记录将不会被保存”，选取消/放弃。尚不能据此判断该提醒使用有效时长还是总经过时间，未猜测门槛。两轮均未新增参考记录，今日/累计仍为3个番茄、22分钟。临时10分钟项保留在归档中，5分钟项保持活动，原默认180分钟及默认主题保持。

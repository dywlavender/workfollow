# 日程子面板按 Flutter 方案重构（2026-09-28）

## 背景

用户在真机验收时逐条纠偏：先是「时间 / 提醒 / 重复」子面板被下方内容遮挡、底部被裁；
接着明确口径——**这几个都是浮动弹窗，不能把原来的弹框扩长**；最后要求
**浮层里不要再出现"时间 / 提醒 / 重复"那一行，直接给选项**。

涉及文件：

- `Features/Tasks/TaskInspector/TaskDatePopoverV2.swift` — 日程面板与浮层
- `Features/Tasks/TaskInspector/TaskDateDraftModel.swift` — 补 `setReminderOffsets`
  与 `syncRecurrenceAnchor`
- 无测试文件改动（草稿模型逻辑未变，XCTest 全量 0 失败）

## 一、Flutter 参考实现（`widgets/task_schedule_options.dart`）

1. `showScheduleOptions`：宽度 = 属性行宽、`anchorRect.top = 行顶`、`gap = 0`、
   `allowFlip = false`，下方不足 160pt 翻到行上方；由 `showTaskEditorPopover`
   以**浮层**呈现（不参与父面板布局）。
2. 文件注释写明："Child menus start at the property row, so the editable/clearable
   active row remains interactive while the menu overlays the properties below it."
   ——**子菜单的头部就是属性行本身**（菜单从行顶展开、盖住行），所以用户只会看到
   一行"时间 09:00 ×"。
3. 度量：行高 34、选项行 34、时间列表 280、提醒 maxHeight 410、重复结束 470。

## 二、原生实现（最终口径）

**属性行 + 独立浮层**：点属性行 → `.popover(arrowEdge: .top)` 从行下方弹出，
浮在主面板之上；**主面板尺寸与布局完全不动**，浮层也不会被裁剪。

```
┌ 主面板（尺寸不变）┐
│ 时间      10:00 ›│  ← 行显示当前值
│ 提醒        无  ›│
│ 重复        无  ›│ ┌ 浮层（独立窗口，浮在上面）┐
└──────────────────┘ │ 09:00 / 09:30 / 10:00 …    │
                     └───────────────────────────┘
```

- **浮层里只有选项**，没有 Flutter 的 `ScheduleOptionsHeader`：Flutter 的头部
  就是属性行（两者是同一行），原生弹窗浮在行下方、行已显示当前值，再画头部
  就是重复（用户明确指出）。
- 清空入口因此改放进选项里（保持能力不丢）：
  - 时间：设了时间时列表首行是「清除时间」；
  - 提醒：取消全部勾选 + 确定 = 清空（Flutter 的 `onClear` 等价）；
  - 重复：选项首行是「不重复」（Flutter 头部 × 的等价）；
  - 重复结束：「永不结束」。
- 选项文案对齐 Flutter：`每天 / 每周 (周三) / 每月 (2日) / 每年 (9月2日) /
  每周一至周五 / 每周六、周日 / 法定工作日 / 法定休息日`；结束后缀
  `永不结束 / 2026年10月26日结束 / 10次后结束`；锚定日随草稿选中日变化。
- 提醒：草稿级多选（`准时 / 提前5分钟 / 提前30分钟 / 提前1小时 / 提前1天` ∪ 已有自定义）
  + 内联「提前 [10] [分钟/小时/天]」+ 取消/确定（确定才写回）。
- 浮层底色必须**不透明**（`.presentationBackground(WFColors.content)`）：默认
  popover 是半透明材质，浮在主面板上会把后面的「确定」按钮糊成一片脏痕。

## 三、走过的弯路（都实测过，别再走）

1. **弹框内 offset 悬浮子面板**（最初实现）：`.popover` 窗口按内容**布局**尺寸开窗，
   超出部分被裁——提醒面板 158pt 高只露 2 行半。
2. **按行顶 + 面板高给弹框预留高度**（`minHeight`）：能解决裁剪，但把主弹框
   撑长留出一片空白——用户否定："不要扩长"。
3. **把面板体放进行的布局里（手风琴）**：不裁剪、点击正常，但同样撑长主弹框，
   还把下面的属性行与底栏顺延下去——同样不符合"浮动弹窗"口径。
4. **`overlay` 挂在行上**：SwiftUI 对超出父视图布局边界的 overlay 内容**不做命中
   测试**——面板画得出来但一个字都点不动。
5. **全屏背板做"点击外部收起"**：`zIndex` 逃不出父容器的层叠上下文，背板把面板的
   点击全吞掉。点击外部收起交给浮层自身的 transient dismiss。
6. **独立无边框 `NSPanel`**：工程已有结论（见 `PlanningOverlayLayer.swift` 注释）——
   拿不到键盘、不继承 environment。浮层继续用 SwiftUI popover。

## 五、遗留

- `deadline`（截止日期）弹框不显示属性行，`initialPage` 只落主页面。
- 时间浮层只有半小时步进（Flutter 头部的 HH:mm 输入框随头部一起去掉）；
  需要任意分钟时可后续在行上补输入。
- 浮层盖住下方属性行（与 Flutter 一致）；要切换面板先点外部收起，或点该行本身收起。

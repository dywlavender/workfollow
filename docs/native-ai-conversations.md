# 三种 AI 对话入口

## 交互

- **选区浮窗**：笔记正文选中文字后，在原有浮动工具条点击“AI 润色”，打开可拖动、缩放的浮窗。支持继续输入修改要求、流式回复及停止。完成后选择替换原选区、在选区后插入或复制。替换与插入沿用编辑器撤销；切换笔记或修改原文后不会写到旧位置。
- **独立对话页**：左侧功能栏“AI 对话”，与任务、笔记同级，也可以通过快速打开搜索“AI 对话”。左侧历史栏顶部放“新对话”，底部放“模型设置”，中间为会话历史；窄窗口通过带文字的“历史对话”按钮打开同一栏。支持连续聊天、停止，记录本地保存。
- **笔记侧栏**：保留当前笔记的整理、润色和待办操作。Pi 模式下，整理/润色及后续补充要求进入同一笔记会话，新对话重置会话；提取待办继续使用原有结构化校验和确认流程。

输入框 Return 发送、Shift-Return 换行；中文输入法确认候选时不发送。选区与笔记侧栏结果继续由用户确认采用；独立聊天收到用户明确的新建或修改要求后，通过 CLI 直接保存并给出记录链接。

历史行在选中或悬停时显示删除按钮，也可以右键选择“删除对话”。确认后删除本地显示记录及对应 Pi 会话；正在进行的回复先取消并等待退出，避免会话文件重新写回。删除当前记录后切换到最近更新的剩余记录，全部删除后回到空白新对话。已创建的待办和笔记保留。

## 共用部分

三个入口共用应用内后端、Pi RPC 进程管理、流式事件、取消及错误处理。选区浮窗和独立页还共用消息区与输入组件。笔记侧栏保留自己的可编辑候选结果和业务按钮。

`conversation.send` 只发送当前消息；首次选区请求另外带上选中文字。Pi 通过 `--session` 恢复自己的会话文件，管理历史、压缩和内部重试，应用不重建压缩后的上下文、不做长短文分段，也不设置额外输入预算。每轮结束或取消后关闭本轮 Pi 子进程，下轮恢复同一文件。

独立页、选区和笔记分别使用 `chat`、`selection`、`note` 场景及独立会话文件。选区入口只带选中文字，不自动携带整篇笔记。独立聊天按用户问题通过 Skill 按需查询和操作 App 内容，不预先灌入整个笔记库。

## 独立聊天的 App 能力

复用仓库 `.agents/skills/workfollow-cli/SKILL.md`，随 App 打包到 `Contents/Resources/Skills/workfollow-cli/SKILL.md`，通过 Pi 的显式 `--skill` 参数加载。无需安装到用户的 Pi 全局目录，也不修改 Pi 模型配置。

独立聊天启用 Pi 内置 `read` 和 `bash`，提供 `WORKFOLLOW_CLI`、`WORKFOLLOW_APP` 环境变量，指向当前应用的原生 CLI 和 App。CLI 路径还加入该 Pi 子进程的 PATH 首位，移动 App 或安装到另一台 Mac 时仍定位当前实例。选区、笔记编辑、纪要等其他场景保持原来的工具策略。

Skill 约定先搜索元数据、按需读取正文，修改前获取最新版本；通过 CLI 保存并核对成功，不直接操作数据库。查询和分析请求只读；用户明确要求记录或调整时执行写入。回复使用简洁说明及可点击的 `workfollow://` 链接，内部版本号和命令不进入普通回复。

新聊天页及选区浮窗固定使用本机 Pi 和既有 Pi 文字模型选择。原笔记业务入口继续兼容此前选择的引擎，Pi 模式复用新增会话逻辑。

## 本地数据

独立页显示记录位于工作区 `modules/ai-chat.json`；Pi 会话位于 `modules/ai-conversations/{chat,selection,note}/`。独立聊天的历史和当前选择在重启后恢复。选区与笔记侧栏在本次编辑会话中各自连续对话。

真实模型复测仅使用虚构代号：第一次回复“已记住”，第二次恢复同一 Pi 会话后正确回复“海蓝752”，两轮分别约 5.19 秒和 1.01 秒。没有发送用户原有笔记、任务或录音。

# 业务菜单视觉统一

日期：2026-10-22；分支：`experiment/macos-native`。

## 目标与范围

第一轮已统一面板定位、生命周期和表单操作栏，但保留了业务 `Menu`，造成同一用途混用两套外观。本轮将业务下拉和业务右键菜单接入共享组件；同类控件遵循同一规范，属性卡、编辑表单和独立窗口仍按用途确定尺寸。

| 入口 | 本轮处理 |
| --- | --- |
| 摘要 | 标签、优先级二级下拉和更多操作接入；保留父级取消/确定的草稿语义 |
| 任务 | 详情清单、批量移动、列表视图/分组/排序/显示设置、侧栏与清单管理、周计划、时间线颜色接入 |
| 日历与四象限 | 视图、更多操作、任务新建卡、规则编辑和移动确认中的选项接入 |
| 专注 | 任务关联、类型、表情、统计筛选、时长、铃声及记录操作接入 |
| 标签、过滤器、倒数日、笔记 | 属性下拉与业务操作接入；倒数日年月日候选共用选项行 |
| 日程卡 | 提醒单位、重复起算方式、每月规则和星期下拉接入；原有草稿提交和日期工作卡保留 |

保留原生：应用菜单栏和状态栏菜单、系统权限、系统确认与文件选择、文本编辑器的系统上下文菜单、分段控件、日期时间字段输入。它们不再算作待迁移的业务下拉。

## 共享实现

- `BusinessMenu`：使用已有 `AnchoredPropertyPanel`，实际按钮锚点、窗口阴影、边缘避让与 Escape 路由继续由同一底座处理。
- `BusinessPicker` / `BusinessMenuChoices` / `BusinessMenuOption`：显式选项、统一选中标记和语义色；任务关联及较长候选列表支持搜索。
- 菜单文字 14 点、行最小高度 32 点、内容边距 6 点、行圆角 6 点、卡片圆角 12 点。一般菜单宽 224 点，优先级等短菜单沿用具名宽度，关联任务宽 320 点。
- 短菜单随内容测高；长菜单列表最多 384 点，搜索固定在列表上方。首次零高度不覆盖有效测量。鼠标悬停不触发滚动，键盘选择和初始选中项才滚动到相应行。
- 根入口点击展开；子菜单首次悬停 220ms，已有子菜单即时切换；离开行只取消待展开动作。关闭、销毁或切换任务后取消延时工作。
- 普通菜单保留来源编辑焦点，通过窗口归属将菜单按键路由到最深子层；带搜索框的选择器打开时聚焦搜索。悬停显现的入口通过绑定呈现状态，在鼠标移入菜单后保持可用。
- 上下箭头跳过禁用项，回车执行，左右箭头进入/返回子菜单；搜索输入保留左右移动光标和输入法行为。Escape 先关闭最深子层。
- 普通动作执行后关闭菜单链，开关项保留菜单以支持连续设置；嵌在摘要“更多”里的下拉只更新父草稿，最终仍由父面板确定或取消。
- `BusinessContextMenu` 复用已有 `PopupInteractionRegistry` 的单一鼠标监听和面板底座，按鼠标位置展示；没有新增全局弹框管理器。

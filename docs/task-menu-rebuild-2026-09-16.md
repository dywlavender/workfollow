# 任务更多菜单改造

分支：`feature/flutter-personal-desktop`。

按参考截图重做菜单，先调整视觉，再接通操作。任务行的省略号和右键共用同一菜单；详情页保留与编辑器有关的工具，沿用相同的图标和行样式。

## 界面

- 菜单宽 264，操作行高 44，正文 15；日期与优先级各有分组标题。
- 日期、旗帜、子任务、置顶、放弃、移动、标签、笔记和删除使用统一线宽的矢量图标。
- 浅色菜单使用白底、灰色分组文字、蓝色选中状态；深色菜单沿用深灰与蓝紫配色。
- “移动到”和“标签”从操作行侧面展开，空间不足时翻转；取消和 Esc 返回上一级。
- 按用户补充要求，从任务行和详情菜单中移除了“复制链接、打开便签、创建副本”。

## 行为

| 操作 | 结果 |
| --- | --- |
| 日期、优先级 | 继续使用统一的任务操作接口，可撤销 |
| 添加子任务 | 打开任务并聚焦子任务输入，再次选择复用已有区域 |
| 置顶 | 在当前清单或日期视图顶部独立分组，可取消，重启后保留 |
| 放弃 | 独立保存放弃状态，取消提醒，不计入完成统计，不生成重复任务的下一期 |
| 恢复 | 在“已完成”页的“已放弃”分组或原清单找到任务，从菜单恢复或撤销 |
| 移动到 | 搜索并选择清单，保留其他属性 |
| 标签 | 搜索现有标签、多选、新建；确定后保存，取消不修改任务 |
| 转换为笔记 | 保留标题、富文本、可勾选子任务、附件和标签文字；原任务退出待办视图，支持撤销 |
| 删除 | 沿用废纸篓和恢复能力 |

## 暴露的问题与处理顺序

1. **模型服务与配置**：当前 Pi 服务出现过明确的 token 速率限制；普通 API 客户端被当前网关拒绝。应处理服务额度与客户端授权，或选择允许通用 API 的服务。App 直接调用模式还需要在设置页保存模型。本次没有替用户切换引擎或修改配置。
2. **错误提示**：Pi 的 `message_end.errorMessage` 中有明确限流原因，现有适配器却统一显示“AI 未返回完整内容”。这会让用户误以为内容处理出错，应显示明确的限流、服务错误与可重试状态。
3. **时延和长文**：普通问答与整理已分别达到约 37 / 44 秒，2926 字润色触及 90 秒上限。应在真实可用服务下继续对照模型速度，并验证长文分段、输出预算和超时设计，不能仅把测试超时延长后称为解决。

本轮没有测试真实录音或讲话人识别；个人原文、任务状态和日用 App 均未改动。完整的虚构输入、输出与耗时见[原始结果](ai-live-results-2026-10-29.json)。

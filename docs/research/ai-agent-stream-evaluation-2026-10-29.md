按用户要求，文字操作使用普通 Agent 对话，应用侧专注提示词、流式展示和业务确认。移除了自建的字节 token 估算、正文分段、摘要合并和续接缓存；删除 `ai_context.py`、`note_jobs.py`、`wf-text.mjs`。本机 Node、Pi 及个人模型配置继续沿用。

## 调用与交互

- Pi 使用正常 RPC Agent，一次提交完整内容，采用工作助理系统提示词。上下文、压缩、模型输出限制及内部重试遵循 Pi 和所选模型配置。
- Pi 的 `agent_end` 之后可能仍有压缩或恢复操作，因此等待 `agent_settled` 才结束。只转发正文，不把推理内容显示为答案。
- 直接调用仍支持两种 OpenAI 协议，使用 LangChain Agent 及框架提供的 SummarizationMiddleware，没有应用自己的输入预判、分段或合并循环。
- 待办、笔记、资料问答、摘要和纪要均有流式展示；结构化任务和问答通过现有库解析预览，只显示可读文字，完成后再校验最终结果。生成过程不写业务正文或创建任务。
- 生成中可取消，保留明确错误与限流等待。正文返回期间刷新等待时间；Pi 压缩阶段不因普通等待时限而提前关闭。保留整个请求的退出清理与传输超时。
- 会议继续每五分钟自动编写、与手动触发互斥，生成中的手动编辑保护不变；语音转写和本地录音路径未改。

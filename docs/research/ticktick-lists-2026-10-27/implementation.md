# 任务清单改造

2026-10-27。依据同目录的 REA 分析，范围为任务清单，不改笔记清单或笔记编辑器。

## 本轮实现

| 区域 | 改动 |
|---|---|
| 新建、编辑 | 共用清单编辑弹窗，集中名称、Emoji、颜色与列表／看板／时间线选择。文件夹、智能清单显示、提醒及默认清单放在折叠的“更多设置”中。取消不修改数据。 |
| 侧栏 | 置顶清单独立排在“清单”上方，不在文件夹内重复显示；一次统计未完成数量。文件夹支持 Emoji、编辑、折叠记忆和拖入清单，解散保留成员。 |
| 清单命令 | 侧栏与清单标题共用编辑、置顶、默认清单、复制、归档与删除规则；保留已有清单动态入口。 |
| 复制 | 提供保留完成状态、重置完成状态、只复制未完成三种范围。保留任务层级、内容、附件、清单分组和视图设置；副本使用独立的任务与周期身份。 |
| 智能清单与提醒 | “在智能清单中显示”和“任务提醒”独立。隐藏影响今天、明天、最近七天与今日组件，普通清单和所有任务仍可查看；静音停止本机及 Apple 提醒事项的任务提醒，保留任务保存的提醒设置。 |
| 默认清单 | 全局快捷添加与桌面组件新增在没有指定清单时使用默认清单；收集箱页面的添加仍留在收集箱。默认清单不能直接归档或删除。 |
| 归档与删除 | 归档任务可查看、选择与复制正文，不能修改；取消归档恢复编辑。界面删除清单会将内容移入垃圾桶，一步撤销恢复清单及任务。原自动化的解散清单接口保持原语义。 |
| 看板 | 按清单记忆尺寸、输入框和检查事项显示；卡片可直接完成检查事项。日期显示沿用现有全局选项。 |
| 保存与兼容 | 新字段支持旧数据库和迁移文件的默认值；清单编辑、文件夹编辑、复制和删除均为单步撤销。 |

清单静音时，周期任务的未来实例也不带 Apple 提醒事项响铃；手机修改标题或时间仍能回写，重新开启提醒后恢复原任务的提醒规则。

## 验证

- 本轮分批执行 41 项不同的相关用例，均通过；没有做全量回归。
- 定向测试覆盖清单保存／取消／复制的真实原生弹窗操作、菜单、归档、持久化、迁移、撤销、默认清单和完整任务页右键路由。
- 在浅色和深色下检查清单编辑弹窗及展开后的布局。
- 补验看板检查事项的实际点击、撤销及隐藏；使用模拟 Apple 提醒事项客户端验证静音、周期实例、手机改期和重新开启提醒。
- 测试宿主使用隔离数据，不创建或改动用户的真实清单与提醒事项。构建、安装检查与实际界面验收分别记录，不以安装成功代替交互通过。
- 日用版已更新至 0.2.0（42），保留 0.2.0（41）用于回退；更新后启动及普通清单切换已确认。安装后的部分菜单未能由鼠标工具可靠打开，未将此记为通过；保存、取消、复制及菜单规则的交互证据来自上述原生测试宿主。

## 范围边界

当前项目没有账号及云端成员服务，本轮没有实现共享邀请、成员权限、链接权限和清单转让，也没有添加不可用的菜单占位。

REA 静态资源尚不能确定滴答普通清单的筛选条何时显示，因此没有将其强制改成所有清单常驻；已有过滤器、分组、排序和时间线继续沿用。此前未实测的滴答功能，不能据此宣称已全部逐项复刻。

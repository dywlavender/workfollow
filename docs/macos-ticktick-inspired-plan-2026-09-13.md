## 1. 参照定位：抄什么，不抄什么

滴答清单是中文个人待办工具里信息架构被验证最充分的参照。打勾与它的产品形态高度同构：单机个人使用、任务 + 笔记、清单与文件夹、日历。因此**信息架构与交互语法值得系统参照**。

但同时要守住这个分支的既有边界（沿用 2026-09-12 方案 §1 的定位判断）：

| 类别 | 取舍 | 说明 |
| --- | --- | --- |
| 信息架构（智能清单/清单/标签/视图矩阵） | ✅ 参照 | 打勾已有同构骨架，缺的是补全 |
| 录入语法（自然语言日期、#标签、优先级） | ✅ 参照 | 纯本地解析，无服务依赖，是最大杠杆 |
| 视图矩阵（四象限/看板/统计） | ✅ 参照 | 全部可由本地任务数据投影 |
| 习惯打卡、番茄专注 | ⚠️ 轻量版 | P2 起步，最小闭环，不做社交化成就 |
| 账号、多端同步、订阅、协作、模板市场、Notion 集成、语音输入 | ❌ 不做 | 超出个人本地版边界 |

原则延续 2026-09-12 方案的两条铁律：**用户看到的结果必须是真的**（统计页只能算真实
completedAt 数据）；**渐进调整不重写**（上轮刚落地的分组卡片视觉是基线，不是要推翻的对象）。

## 2. 滴答做对了什么：逐条拆解

1. **录入快过一切。** 快速添加支持自然语言："明早九点开会""9月20号下午三点取件"会自动设置
   日期、时间与提醒；`#标签`、`~清单` 随手打。录入摩擦是待办工具的第一流失点。
2. **一份任务数据，多种视图。** 同一清单可在列表、看板、四象限、日历之间切换；四象限按
   重要/紧急投影，看板按分组维度投影。数据模型不随视图膨胀。
3. **清单有颜色，颜色贯穿全局。** 清单色出现在侧栏、列表行左侧色条、日历事件、看板卡片上，
   扫一眼就能分辨归属——这是滴答界面"信息密度高但不乱"的关键。
4. **三栏结构，详情常驻可选。** 侧栏 → 列表 → 详情，详情栏可折叠；点击任务即看全部属性，
   不依赖展开状态。
5. **智能清单替用户做预筛选。** 今天、明天、最近 7 天、过期、已完成——由日期推导，不要求
   用户自己维护过滤器。
6. **统计页把坚持变成可见资产。** 完成趋势（日/周/月）、任务热力图、清单分布环图，全部来自
   真实完成记录。
7. **回顾机制。** 每周摘要把"上周完成了什么"主动呈现在首页，而不是让用户去翻。
8. **批量与快捷操作成熟。** 左滑快捷设日期/提醒、多选批量、拖拽排序、置顶清单、隐藏已完成。

## 4. 设计原则

1. **录入快过一切。** 任何任务都应该在一行输入内完成 90% 的信息（标题 + 日期 + 清单 +
   标签 + 优先级），点选面板只负责剩下的 10%。
2. **视图是任务数据的投影。** 四象限、看板、统计都只读同一份 `TaskItem`，不在视图层造新
   状态；切换视图不改数据。
3. **颜色必须成体系。** 清单色板是唯一的色彩来源之一，侧栏/行/日历/看板/统计共用，禁止
   各页面自定颜色。
4. **看到的结果必须是真的。** 统计、回顾、连续天数全部从真实 `completedAt` 计算，缺数据
   就显示空态，不造演示数字。

## 5. 分项设计规格

### 5.1 快速录入的自然语言解析（P0，最大杠杆）

**语法规格**（中文优先，全部可关）：

| 输入片段 | 解析结果 | 示例 |
| --- | --- | --- |
| 今天 / 明天 / 后天 / 大后天 | 对应日期 | `后天交报告` |
| 周X / 星期X / 下周X / 下下周X | 最近/下一个对应星期 | `周五理账` |
| M月D日 / M月D号 / M/D | 今年（已过则明年） | `9月20日取件` |
| 明早/明晚/后天早上 + H点 | 日期 + 时刻 | `明早9点晨会` |
| H点/H点半/H:MM/HH:MM | 当天或当天之后最近时刻 | `下午3点打电话` |
| X小时后 / X天后 | 相对时间 | `2小时后回访` |
| 每天 / 每周X / 每月X号 | 重复规则 | `每周一例会` |
| `#词` | 标签（复用已有 tags） | `#工作` |
| `@清单名` | 目标清单（须已存在，防误建） | `@个人` |
| `!`/`!!`/`!!!` | 低/中/高优先级 | `!!!立即报修` |

**交互规格**（对齐滴答的"识别可见"）：

- 输入时实时解析，**命中的片段在输入框内以淡色 chip 样式内联高亮**（滴答同款做法），
  光标处显示解析摘要行："→ 9月15日 09:00 · 提醒 · #工作"。
- 识别结果可一键取消（点击 chip 上的 ×），避免误识别后找不到入口。
- 解析器为纯 Dart 模块 `lib/services/smart_date_parser.dart`：
  `ParseResult parse(String input, {required DateTime now})`，输出
  `{title, dueAt, hasTime, reminderAt, recurrence, tags, listName, priority, spans}`。
- 接入三处：任务页 QuickAddField、首页 QuickAddField、原生菜单栏全局录入
  （`workfollow/capture` 收到文本后走同一解析管线，Swift 侧零改动）。
- 模糊时间（"9点"在下午输入）按滴答规则取未来最近时刻，解析预览让用户可确认。

### 5.2 清单色板与颜色贯穿（P0）

- `MigrationListRecord` 增加可选 `color`（字符串 hex，缺省由清单名 hash 从 14 色板取色，
  旧快照读取完全兼容）；`MigrationTaskRecord` 不动（任务归属靠 listName 查色）。
- 14 色板取滴答同级观感：红/橙/黄/橄榄/绿/薄荷/青/蓝/靛/紫/品红/灰褐/石板/灰。
- 视觉映射点：
  1. 侧栏清单项：图标换成色点（滴答式），选中态用同色淡化底；
  2. 任务行（卡片模式）：行首加 6px 清单色竖条或色点；
  3. 日历事件与首页任务行：沿用清单色；
  4. 看板/四象限（后续视图）自动继承。
- 设置 → 外观里提供"清单颜色"说明项，编辑清单弹窗加色板选择。

### 5.3 标签入口（P0）

- 侧栏"任务"分区下新增"标签"小节：列出全部任务标签 + 计数（数据已在 `TaskItem.tags`，
  控制器补 `allTags()` 聚合与 `selectTag(name)` 过滤）。
- 点击标签 → 任务列表按标签过滤（复用现有列表视图，头部显示"标签：工作"）。
- 任务详情的标签胶囊保持现有编辑弹层；长按/右键侧栏标签可重命名（批量改 tags）与删除。

### 5.4 每周回顾卡（P0）

- 首页在问候头下新增"上周回顾"横幅卡（仅周一～周三显示，或提供关闭偏好）：
  "上周完成 23 件 · 周三最高产 · 还有 2 件逾期未清"。
- 全部由 `completedAt`/`dueAt` 聚合，无新存储。

### 5.5 统计页（P1）

新增侧栏"位置"分区下的"统计"（`WorkspaceView.stats`），布局：

```
┌──────────────────────────────────────────────────────────┐
│ 统计                                   [本周 | 近30天]     │
├──────────────┬───────────────────────────────────────────┤
│ 今日完成  5  │  完成趋势（近30天柱状图，可切 周/月 聚合）   │
│ 本周完成 23  │  ▂▃▅▂▇▅▁▃▄▆▂…                              │
│ 逾期    1    │────────────────────────────────────────────│
│ 进行中  12   │  热力图（近 16 周日粒度，GitHub 式点阵）      │
├──────────────┴───────────────────────────────────────────┤
│ 清单分布（环图：工作 42% · 个人 31% · 学习 27%）            │
└──────────────────────────────────────────────────────────┘
```

- 实现建议：`lib/screens/stats_screen.dart`，聚合器 `StatsAggregator` 纯函数 +
  单测；图表手绘（CustomPaint）或 `fl_chart` 二选一，先手绘三张小图避免引依赖。
- 空态明确："完成第一件事后，这里会开始长出你的节奏。"

### 5.6 四象限视图（P1）

- 新增 `WorkspaceView.matrix`，侧栏"位置"分区加入口，⌘6 快捷键。
- 象限规则（个人版固定，不做可编辑规则，降低复杂度）：
  - **重要** = 优先级 ∈ {高, 中}；**紧急** = 逾期、今天、或 3 天内到期。
  - 四格：立即做（重要紧急）/ 安排做（重要不紧急）/ 委托看（紧急不重要）/ 缓一缓。
- 每格是可折叠的任务组卡（复用现有 `_cardSide` 体系）；**跨格拖拽** = 改优先级或改期，
  拖入"立即做"默认设为今天。
- 顶栏显示"仅看未完成"开关（默认开）。

### 5.7 看板视图（P2）

- 以清单为单位开启：清单标题栏 ⋯ 菜单 → "看板视图"；或全局"所有任务"的看板模式。
- 分组维度下拉：优先级 / 日期（本周、下周、以后）/ 状态（未开始·进行中·已完成——需要
  给 TaskItem 补一个轻量 `inProgress` 布尔，或首期只做前两种维度，避免新状态）。
- 首期推荐只做 **优先级 / 日期** 两维（零模型改动）；卡片 = 现有 TaskRow 的紧凑变体，
  拖拽换列映射回优先级/日期字段。

### 5.8 习惯打卡与番茄专注（P2，轻量闭环）

- **习惯**：`HabitItem {id, name, icon, color, schedule, records[]}` 进本地快照
  （migration schemaVersion +1，旧文件兼容）；侧栏"位置"分区"习惯"入口；
  页面 = 今日打卡列表 + 每个习惯 28 天点阵 + 连续天数。不做成就/等级。
- **番茄**：菜单栏图标点击 → 25 分钟倒计时（可设 15/25/45）；结束发系统通知
  （复用 NotificationService）；任务详情显示"累计专注 n 个番茄"（TaskItem 增
  `focusCount`，可选字段）。统计页加一行专注计数。不做白噪声/社区。

### 5.9 布局与密度微调（P1）

- 上轮的分组卡片保留为默认"舒适"密度；设置 → 外观加 **密度：舒适 / 紧凑**。
  紧凑模式：列表去卡片改满宽扁平行（行高 40、hairline 分隔、行首清单色条），
  即滴答式信息密度，服务长清单用户。
- 宽窗（≥1200）提供可选"**详情常驻**"三栏模式（右侧详情面板 320px，点任务即显示）。
  常驻详情默认只呈现顶部常用操作、标题与正文；清单归属、更多属性和更多操作集中在底部
  工具条，截止日期、标签、专注、子任务、附件与关联通过"显示更多属性"渐进展开。行内展开
  仍保留同一套编辑能力，窄窗回退逻辑不变。

| 习惯/番茄（P2） | `models/habit.dart`、通知复用 | schemaVersion 再 +1 |
| 侧栏标签区/色点 | `widgets/sidebar.dart`、`widgets/task_row.dart` | 视觉调整 |

风险与缓解：

1. **NLP 误识别** —— 一切识别都内联可见 + 可点掉；解析器 100% 单测覆盖词表。
2. **侧栏膨胀**（清单/标签/视图变多）—— 标签区默认收起为"标签 (n)"可展开；
   新视图只进"位置"分区。
3. **统计页性能** —— 聚合器 O(n) 单遍，千级任务无压力；后续可缓存。
4. **实施顺序** —— 本仓库有未完成的合并（SettingsPage.vue 冲突）；动手前先由使用者
   解决合并，避免把桌面改动混进合并提交。

## 8. 验收场景

1. **自然语言录入**：在今天页快速添加输入 `明早9点 #工作 @个人 !!!准备评审`，按 Return ——
   任务标题为"准备评审"，日期明天 09:00，带提醒，清单"个人"，标签"工作"，高优先级；
   输入框清空后列表立即出现该任务。
2. **识别可撤销**：输入 `周五理账` 后点掉日期 chip，提交后任务无日期，落入收集箱语义。
3. **颜色贯穿**：把"工作"清单改为绿色后，侧栏、今天页行首、日历事件、首页任务行
   同步变绿；重启应用颜色保留。
4. **标签过滤**：侧栏点"工作"标签，列表只剩含该标签的任务；头部显示"标签：工作"。
5. **统计真实**：清空数据库后统计页各图为空态；完成 3 件后柱状图 +3、热力图今日格变色，
   与"已完成"视图计数一致。
6. **四象限**：把"重要不紧急"格的任务拖入"立即做"，任务优先级不变、日期变为今天；
   逾期任务自动出现在"立即做"。
7. **密度切换**：切到紧凑模式，长清单（80+ 任务）一屏可见 ≥14 行，行内展开编辑仍工作；
   重启后偏好保留。
8. **全局录入走解析**：⇧⌘Space 输入 `明天下午3点取件`，主窗口今天/明天视图出现该任务
   且日期正确（解析在 Dart 侧，原生面板无改动）。

## 9. 详情栏减法修订与本轮验收（2026-09-14）

对照本机滴答清单的任务详情栏复核后，原先“一次性展示全部属性”的实现与参照物不一致，
也造成选中任务后的视觉噪音。本轮按“正文优先、细节按需展开”收敛：

- 默认视图仅保留顶部完成/安排/提醒/重复/优先级操作、任务标题、备注正文，以及底部清单归属、
  保存状态图标、更多属性和更多操作。
- 截止日期、标签、专注记录、子任务、附件与笔记关联全部移入可收起的“更多属性”区域；
  原有编辑、添加、删除和打开关联的行为不删除。
- “复制任务正文、创建副本、移到废纸篓”从顶部移到底部更多操作，减少固定操作条的拥挤。
- 新增组件验收覆盖：默认隐藏高级内容，点击“显示更多属性”后内容完整出现并可再次收起。

验证结果：`flutter test` 通过 106 项；`dart analyze` 无 error，只有 2 项已有
experimental warning 和 19 项 deprecated info；`flutter build macos --release` 成功。Release 原生截图复核需在
Mac 解锁后补做，本轮不把锁屏状态下无法观察到的视觉结果记为实机通过。

## 10. 明确不做

账号与多端同步、订阅与付费、协作共享、团队日历、模板中心、社区、Notion/第三方集成、
语音输入、桌面小部件商店。若产品定位扩展，另立方案再评估。

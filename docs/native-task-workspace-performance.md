# 任务工作区与主题渲染

任务清单共用一个页面宿主、一个 NSOutlineView 和一份详情编辑器。切换“今天、收集箱、所有任务”等清单时更换列表投影，不再保留多个同时观察任务选择的完整工作区。清单的上下文、草稿、分组折叠、完成任务分页和滚动位置分别保存。

`TaskDataObservation` 只转发数据、日期、筛选和列表展示状态变化。`TaskLayoutObservation` 额外观察是否有选中项及分栏宽度，切换两个已选中的任务不会重新计算整个工作区。详情仍观察当前任务；列表直接更新旧行和新行的选中状态。行内容另有更新版本，内容编辑不会因复用而漏刷。

列表缓存最多 64 个行宿主，按清单和行身份复用。复用的是行控件，不是隐藏的整页详情。内容与布局未变时不重绑控件；清单键变化但行结构未变时不强制重载。返回清单时会同步当前选中状态，避免旧高亮残留。标签分组保留组身份，允许同一个任务出现在多个标签组中。

标题和正文提交对照存储版本，只在确实修改任务后推动工作区刷新。合并时保留了原目录的 `unchanged` 动作结果及组合编辑规则。

快速添加草稿使用 `listQuickAddDraft.v2.<scope>`，首次访问时接收原先按页面保存的 v1 草稿。不同清单、标签和过滤器各自恢复草稿。正文切换仍同步提交旧任务的输入法组合串，并保留编辑器自身的撤销边界。

主题底图、云朵、贴纸、气泡和极光元素通过 ImageRenderer 生成可复用图像。Core Animation 负责位置、旋转、缩放和透明度动画；不再由 TimelineView 每帧构造背景视图树。窗口失活或系统要求减少动态效果时暂停。图像缓存目标设置为 64 项、64 MiB；底图采用 1 倍栅格，装饰采用最多 2 倍栅格。

测量使用固定的 58 条虚构任务和 1280×800 原生窗口，详见 `research/task-workspace-performance-2026-11-01.json`。改造前的任务切换中位数约 220–250 ms，最终合并源码的测量为 26–27 ms；动态主题空闲时的进程 CPU 时间由每秒约 1 秒降至几毫秒。首次创建清单的行控件仍有成本，首次进入清单约 143–200 ms，已缓存清单约 51–55 ms。数字属于 Debug 下的原生更新、布局与绘制阶段，不代表物理鼠标到屏幕显示的精确延迟，也不包含合成器或 GPU 成本。

原生回归包含清单切换与宿主身份、草稿/滚动恢复、选中行和旧高亮清理、正文与输入法保存、右键、多选、列表内容更新，以及背景图层复用和暂停。四套主题的原生静态图已检查。最终合并源码的定向回归共选择 81 项，实际执行并通过 80 项，1 项因隔离存储没有足够任务而跳过；没有失败。

另外执行了快速添加的 2 项原生日期回归，确认“明天下午3点开会”在回车创建及恢复草稿后仍保留安排日期；均通过。本轮合计 82 项通过，1 项跳过，没有失败。

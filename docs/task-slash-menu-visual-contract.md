# Task Slash 菜单呈现规范

依据用户提供的滴答 / WorkFollow 菜单截图，2026-10-02。

- 紧凑 Task 菜单：当前行用中性灰圆角底，不叠加强调色描边；键盘和鼠标选择使用同一呈现。
- 卡片无硬边框，阴影由 NSPanel 提供。卡片圆角 16pt，行圆角 8pt。
- 保留 160pt 宽、34pt 行高、动态内容高度及原有定位逻辑，不靠拉长卡片补缺失菜单项。
- H 图形必须完整位于画布内，级别数字靠右下；引用使用弯引号，分割线采用虚实组合。
- 父任务有「子任务」，现有子任务按 Domain 层级约束隐藏该入口；不得为截图一致而绕过层级规则。
- Note 命令目录、输入和业务动作不变。

验证：39 项 DocumentProfileTests / SlashSessionTests 通过。父任务完整 12 项目录、子任务 11 项目录及宿主动作路由均有回归覆盖。明暗模式真实测试窗口截图已检查：`/tmp/render_task_slash_light.png`、`/tmp/render_task_slash_dark.png`。

边界：截图为测试窗口渲染，不是运行中主 App 的完整点击流程；不宣称逐像素一致。

# 正式滚动纪要接入 skill

## 接入

- 唯一规则源为 `.pi/skills/meeting-minutes/SKILL.md`，通过 Xcode Resources 引用打包成 App 内 `SKILL.md`，不是维护第二份规则。
- 内置 Pi 扩展明确读取规则，用作 Qwen 实时文字路径或普通文字模型路径的系统指令。不依赖模型自动发现 skill。
- 配置自定义音频扩展时，原普通 Pi 文字路径以显式 `--skill` 和 `/skill:meeting-minutes` 加载包内规则。
- 没有新增转写时，Native 原样返回旧纪要，不启动 Pi。Store 已处理过的转写也不重复发请求。
- 不修改音频转写、录音分段或讲话人标签机制；常驻音频实验仍不进入正式流程。

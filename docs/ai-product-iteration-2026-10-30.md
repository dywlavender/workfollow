# AI 日常工作流程优化

沿用原生业务存储、App 内 AI 后端与 Pi 会话管理。明确操作直接执行；生成内容继续采用现有草稿确认。功能集中在现有入口。

## 实施清单

- [x] 待办 CLI：提醒、重复规则、日期范围及准确统计；同步内置 Skill。
- [x] 查询：独立对话支持会议查询和发言来源，引用当前笔记或任务。
- [x] 执行反馈：原生操作回执、实际字段、打开及撤销。
- [x] 对话：指定回合重试、复制、继续回复、块级 Markdown、准确工具状态。
- [x] 配置：明确 Pi 对话实际模型、快捷切换、Node/Pi/模型/Skill 检查。
- [x] 会议：录音定位回放、转写和讲话人校正、录音重新转写。
- [x] 定向回归、虚构资料实测、发布包验证与日用版更新。

## 验证原则

使用独立目录中的虚构待办、笔记、会议和合成录音。真实模型测试仅发送虚构资料；正常日用数据只用于确认界面是否保留，不用于模型质量测试。识别准确率与讲话人自动分离不以代码或模拟回归代替实录结论。

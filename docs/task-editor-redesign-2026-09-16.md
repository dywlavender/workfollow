# 任务编辑器改造

分支：`feature/flutter-personal-desktop`。依据文字方案与用户补发的目标图，沿用 Quill 文档、TaskActions 和现有 Popover。

## 界面与交互

- 顶部固定完成按钮、安排日期和右侧优先级。提醒、重复只在已设置时显示；安排日期逾期标红，已完成任务日期弱化。固定详情去掉关闭按钮。
- 删除正文清单、截止日期、标签 Chip。正文左侧固定 40px、顶部 30px，标题和正文间距 10px；取消 820px 居中宽度限制。
- `TaskEditorViewport` 按标题实际高度分配正文剩余空间。短文填满面板，长文随外层页面滚动；旧任务子任务、附件和来源面板紧接正文，下面空白也可点击编辑。
- 底部保留清单、格式和更多操作；正常保存静默，失败时显示重试按钮。
- 更多菜单按补充截图改为独立的紧凑菜单；提醒、重复位于日期弹框，截止日期、专注记录位于 `/` 菜单。详见[四个弹框验收记录](task-editor-popovers-2026-09-16.md)。
- 按菜单任务中用户后续补充要求，菜单排除复制链接、打开便签和创建副本。
- 打开详情只获取面板焦点；点击标题或明确请求标题编辑才进入输入状态。保留挂载前发出的标题编辑请求。
- Esc 依次退出弹出层或 Slash 菜单、编辑焦点、行内或窄屏详情。固定详情保持选中。

## 验证范围

新增 `task_inspector_layout_test.dart` 覆盖正文空白输入、窗口缩放、长文滚动、优先级和底部对齐、Esc 分层、窄屏返回、标题焦点、旧文档子任务、更多菜单属性迁移以及保存失败重试。同步更新既有编辑器和菜单回归断言。

验证结果：完整 Flutter 回归 202 项通过；macOS Release 构建通过；`dart analyze lib test` 无错误，保留现有 4 条 Quill 实验 API 警告和 4 条设置面板 API 弃用提示。

# 编辑区滚轮与滚动条修复

## 原因与范围

笔记使用随正文增长的 Quill WebView。内部滚动关闭后，WebView 仍接收滚轮，外层 SwiftUI ScrollView 没有接到事件。任务详情仍使用原生编辑器，本次保留其已有滚动路径。

## 改动

- 只在正文当前可见范围内，将上下滚轮的原始 NSEvent 转交外层 NSScrollView，保留方向、阶段和惯性信息。
- 横向滚动、固定视口及斜杠菜单的内部滚动继续交给 WebKit。菜单打开、关闭和尺寸变化时更新命中区域，不逐帧查询 JavaScript。
- 编辑正文、任务详情、任务列表和清单侧栏统一使用细悬浮滑块；原生滑块绘制宽度上限 6 点，保留原生拖动与翻页入口。Web 滑块宽度为 6 CSS 像素。
- 固定视口明确约束正文高度，正文区域自行滚动；随内容增长的笔记只由外层页面滚动。
- 同步更新 Quill 运行时包和缓存版本，避免继续加载旧 CSS 与桥代码。

## 验证

- 16 项相关测试通过：EditorScrollRoutingTests、QuillBridgeSpikeTests、DocumentEditorHitTargetTests、NativeTaskOutlineTests。滑块初始化调整后，再跑 3 项滚动测试通过。
- 隔离签名应用加载实际 Quill 宿主与运行时包，使用 80 段模拟正文。鼠标向下滚动一页，记录到原始滚轮事件转交，外层偏移从 0 变为 650；反向滚动后返回中间位置。
- 隔离运行测量：增长型正文内部偏移始终为 0；固定视口正文高度大于视口且 overflow 为 auto；两者 Web 滚动条计算宽度均为 6px。原生宿主使用 CompactOverlayScroller。
- Release 0.2.0 (14) 构建和应用包验证通过，安装包不包含验收存储配置。
- 截图工具只返回失真的窗口缩略图，不能据此认定最终日用窗口的外观已验收。此轮没有覆盖日用安装版。

验收应用已正常退出并移除；测试内容未写入日用任务或笔记。

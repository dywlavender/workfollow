# 多级列表、RTF 与编辑器弹层

日期：2026-10-25。接续[编辑器统一改造](implementation-and-acceptance.md)。

## 实施结果

### 多级列表与按键

列表新增层级和有序起始编号，保存到现有 Delta 的 `indent`、`wf-list-start`。旧块数据缺少字段时按零层级读取。当前层级范围固定为 0…8；这是本项目的实现策略，未声称已验证滴答的最大层数。

- Tab 增加层级，Shift+Tab 减少层级；移动父项时后代随行，保留相对层级。
- 支持选中多项一起缩进，正文不插入伪造空格或 Tab 字符。
- 有内容项回车续同级，新检查项为未勾选；空项回车先退一级，在根层退出列表。
- 缩进项行首退格先退一级，正文和代码保持原输入路径。
- 父级编号跨过子级继续计数；输入 `7. `、HTML 的 `start/value`、RTF 起始编号可以保留。
- 缩进、续项支持单步撤销和重做；任务、笔记切换及重启后保留层级。
- 内部片段、Markdown、HTML 嵌套列表和 RTF 列表链均接入层级；空的末尾列表项继续输入时保留层级。

文字缩进、换行缩进和装饰标记使用同一份层级数据，避免只移动圆点、文字仍留在原位。

### RTF 标题

`DocumentRTFStructureCodec` 先沿用 Cocoa 还原文字、字体和列表，再从 RTF 的 `outlinelevel`、段落样式和样式继承恢复标题。支持明确的 Heading N／标题 N 样式名。导出保留 Cocoa 的完整内容，并补标准标题级别，正文段落明确复位。

同时含 HTML 和 RTF 的剪贴板，若两份正文完全一致，可用 RTF 的明确标题信息补足 HTML 普通段落，保留 HTML 的其它结构和格式。不会依据大字号或粗体猜标题；源 RTF 已经没有标题元数据时，仍按正文处理。

### 弹层与提示

- 标题和时间菜单复用已有 `AnchoredPropertyPanel`，保留正文选区；点击外部或按 Esc 关闭，指针经过菜单缝隙不会导致提前关闭。
- 维持标题 150 点、时间 222 点的理想宽度和既有行高；可用空间较小时限高滚动，弹层不能撑大主窗口。
- Slash、标签／清单候选、选区工具条和链接菜单统一依据窗口内容与屏幕可见区域定位，空间不足时翻转或收窄。
- 标签候选跟随正文滚动及窗口移动；选区工具条可横向滚动；提示文字左右夹入工具条范围。
- H4…H6 也能正确显示标题激活状态。

## 证据与验证

已有 REA 证据包含滴答 `APMarkdownTextView.handleTabWithIsBack:` 和列表主题字段；这些证据证明存在专门按键路径，不单独证明本表每项具体规则。实时参考截图工具本轮报捕捉失败，具体行为按本项目实现和验收结果分别记录。

- 最终 **237 项编辑器相关用例通过**，按不同用例计数，包含修复后重跑的失败组；模拟数据准备用例另计，不计入该数量。
- 覆盖列表存储、层级编号、复制粘贴、RTF 标题、格式、任务／笔记宿主，以及弹层定位、选区保留和关闭行为。
- 完整任务页的 `NSApplication` 按键分发测试发现 Shift+Tab 曾进入普通 Tab 分支，已在 `keyDown` 入口按实际修饰键区分；相关 58 项回归通过，确认正文焦点与导航保持不变。
- 候选框旧的固定 176 点断言已改为验证理想高度上限与窗口可见边界，受影响的 3 项用例重跑通过。
- Release **0.2.0 (20)** 构建与交付包校验通过，包含最终 Shift+Tab 修复。日用安装版未替换。
- 用户在修复后的隔离副本手动验证列表 Tab／Shift+Tab，以及标题／时间菜单的位置、指针移入、Esc 和外点关闭，反馈“验证好了 没问题”。该结果与自动化按键分发测试分别记录。
- 验收副本已正常退出，临时 QA 应用、模拟数据及过期候选包已清理。随后按用户 2026-10-25 的清理要求，一并移除可重建的最终候选包；源码和验证记录保留。

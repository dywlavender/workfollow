# 编辑器统一实施与验收

日期：2026-10-25。基于 `experiment/macos-native` 当前源码实施用户选定的五项改造。

后续多级列表、RTF 标题和弹层优化见[补充实施记录](lists-rtf-popovers.md)。

## 对齐依据

- 参考本机滴答 8.0.80 (492) 的 REA 类元数据：任务和笔记详情复用原生 `APMarkdownTextView: NSTextView` 体系。
- 用户实测确认：输入 `#` 出现候选，接着输入空格转成 H1，`# ` 不在编辑面中显示，继续输入沿用标题格式。
- AX 中保留 Markdown 文本不能证明编辑面显示源码。此前的源码模式推断已撤回，本批沿用原生富文本内核。
- 原始差异调查保留在 [任务编辑器对比](task-editor-comparison.md)；本文件记录后续实施结果。

## 已实施

| 项目 | 结果 |
|---|---|
| 结构化复制粘贴 | 应用内部使用带段落边界的文档片段，保留标题、编号、检查项、引用、格式、附件与流程图；整块与局部选区按不同边界合并；粘贴是一组正文撤销。 |
| 公共剪贴板 | 同时提供语义 HTML、RTF、Markdown。导入按 HTML 语义、RTF 段落元数据或 Markdown 还原；保留空段和代码围栏；代码上下文保留字面输入。 |
| 折叠布局 | 外层高度和原生子任务树使用同一份可见节点计数；统一过滤已移除节点、行高与行间距。折叠子树后添加行立即跟随，保留内层折叠状态。 |
| Markdown 手感 | `#` 候选到空格 H1 与菜单 H1 共用命令路径；任务和笔记共享 14 点正文、格式入口及工具条；空格式块隐藏普通正文占位；候选超过六项可滚动和键盘访问。 |
| 笔记共用编辑器 | `NotesWorkspaceView` 使用 `DocumentEditor → NativeTextView`，保留 Note profile、关联任务、文件夹和收藏能力；笔记切换沿用文档重绑定与组合输入提交机制。 |
| 笔记入口 | 详情、右键菜单、批量“转换为笔记”统一修改原任务的 `TaskKind.note`；可转回任务；保留任务 ID、清单、层级及正文，停留在任务页。原独立笔记库及数据保留，跨模型归档接口明确命名为 `moveTaskToNoteLibrary`。 |
| 已有数据 | 持久化继续使用现有 Delta 适配器；补充标准 Quill 图片 embed 的读取，内嵌图片字节保留为原生附件，远程图片地址保留为链接。 |
| 滚动与浮层 | 笔记正文使用外层滚动，细滚动条跟随宿主后续的样式重设；格式浮层挂载在完整详情区域。 |

## 验收记录

- 最终合并定向回归：**197 项全部通过**。覆盖剪贴板、流程图、文件粘贴、折叠与子任务、Markdown 候选和触发、格式工具条、笔记宿主、类型转换及相关菜单契约；没有执行日历、专注等无关全量回归。
- 完整 Inspector 验证外层折叠占位与添加行位置；笔记宿主验证组合输入切换、分别保存后重新读取，以及通过实际渲染的按钮应用格式。
- 批量原位转换、单步撤销/重做、旧独立笔记库归档接口及标准 Quill 图片读取均通过。
- Release 构建和包校验通过。实施文件与经过测试的构建快照逐字节一致；日用安装版未被覆盖。
- 隔离副本 `WorkFollow Editor QA`：已通过真实按钮打开笔记格式工具条，并对选中正文加粗，AX 文本随之更新。副本只含模拟数据。
- 用户在同一隔离副本完成两项手动验收并反馈“两项都正常”：长笔记的滚轮上下与细滚动条正常；展开、折叠子任务后，下方添加行跟随上移，没有大块空白。这是实际交互确认，与自动化测试和构建结果分别记录。
- 验收结束后已正常退出隔离副本，清理本轮 QA 应用、模拟数据和临时种子用例。随后按用户 2026-10-25 的清理要求，一并移除可重建的 Release 候选包；源码及验收记录保留，日用版未替换。

## 对齐边界

RTF 经 Cocoa 读写可能丢弃 `headerLevel`。本批只按真实段落元数据识别标题，不用字号猜测；应用内部片段和语义 HTML 可以保留标题。系统截图工具仍返回失真缩略图，暂无新的逐像素尺寸一致性结论。现有证据支持本表列出的行为，不等于滴答整个编辑器已逐项完全一致。

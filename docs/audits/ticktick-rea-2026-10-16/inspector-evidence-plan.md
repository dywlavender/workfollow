## 探针方法备注（供后续探针复用）

- 滴答自绘控件对 AppleScript `click at` 与 AXPress 普遍不响应（AXPress 会"假成功"）；**可靠组合 = AX 读取精确坐标 + CGEvent 合成鼠标/键盘**。
- 弹出菜单的 AX 坐标相对实际渲染存在约 (−57, −40) 偏移；菜单项执行建议用 CGEvent 键盘（↑/↓ + Enter）——实测对"永久删除"有效。菜单可被 CGEvent 键盘驱动（AX 合成键盘事件无效，不能据此判定滴答不支持键盘）。
- 垃圾桶任务行不可打开详情；删除入口为行右键菜单（恢复 / 永久删除）；删除任务快捷键为 ⌘⌫（进垃圾桶）——**需列表焦点**，稳定序列 = CGEvent 点击任务行 → ⌘⌫。
- 弹层（菜单/浮窗）的 AX 窗口位置含约 +44pt 偏移（右上方向），尺寸含阴影（如 Slash 菜单 AX 报 240×505、实测内容 ≈156×430）；**测量以 1:1 截图目测为准**，AX 值仅作参考。
- "添加任务"输入框：AXPress + AXFocused 验证/强制聚焦后再 keystroke 才可靠（纯 `setValue` 写入不会触发滴答的提交状态）。
- 本地 app（WorkFollow）实测注意：点击列表行文本可能进入**标题编辑**（此时 ⌘⌫ = 删行首，会截断标题——2026-10-17 踩过）；选中行请点行右侧空白，删除任务用 footer"…"菜单 → "删除"项。

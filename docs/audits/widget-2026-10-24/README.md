## 已实施

蓝色「今天＋总数」标题、独立加号、圆角方形勾选框、四行列表、中文月日、蓝色当天/时间标签、红色逾期日期；移除组件中的日期标题、底部统计与周计划入口。

普通任务的勾选与打开详情分区保留。倒数日复用项目既有智能清单显示规则，置于任务前，以圆底图标显示，点击进入倒数纪念日模块；不会生成任务完成命令。标题统计当天符合条件的任务与倒数日总条数，卡片最多显示四条。周计划仍由主应用提供，旧组件的周计划链接继续可用。

倒数日快照提前准备当前日及未来七天；新增、改名、归档和跨天会触发快照更新。原有不含倒数日字段的快照仍能读取。没有新增用户设置项，也没有复制真实任务到验收数据。

## 验证边界

18 项组件相关用例通过，覆盖完成持久化、重复请求、快照、倒数日规则及刷新、导航和快速新增；没有运行全量回归。浅深色共十二份隔离渲染覆盖正常、纯任务、多任务、空状态、未加载，以及紧凑尺寸。正常尺寸按参考图检查 29 点行距，并通过图标像素检查最后一行没有裁切。

预览由 NSHostingView 使用模拟任务渲染，内容区为 344×164 点；圆角、阴影和桌面材质由实际 WidgetKit 容器提供，预览不是桌面运行截图。当前没有将测试通过视为新版组件的真实桌面点击验收。隔离 Release 0.2.0 (14) 构建与包校验均通过。

构建期间编辑器仍有并行改动，本轮没有替换日用安装版。

# 打勾 macOS 个人版

`feature/flutter-personal-desktop` 分支上的 Flutter 桌面应用：单用户、本地优先的任务与笔记工作台。产品定位、评估与分阶段方案见 [`docs/macos-productization-plan-2026-09-12.md`](../docs/macos-productization-plan-2026-09-12.md)；旧设计基线见 [`docs/macos-personal-app-design.md`](../docs/macos-personal-app-design.md)。

## 已实现能力（截至 2026-09-12）

**可信度与数据**
- 本地 JSON 快照持久化，真实保存状态（保存中/已保存/失败）展示在编辑器底部；快照损坏时保留原文件并暂停自动保存，导入数据可覆盖
- 每日自动备份（保留最近 7 份）+ 设置页“立即备份”
- 任务与笔记统一软删除，持久化废纸篓（恢复 / 永久删除），批量操作可通过撤销回退
- 导入 Web 迁移文件：可选“合并到本机”或“清空本机后导入”
- 旧文件格式向后兼容（缺省字段按空处理）

**任务**
- 新建继承当前清单/日期上下文；无日期任务不再占用“今天”
- 真实重复任务：每天 / 每周指定星期 / 每月指定日期（月末钳制）；完成生成下一次，撤销同步还原
- 子任务实体（增删改/勾选）、标签、优先级、日期与提醒
- 多选批量操作（Cmd/Ctrl 点击、Shift 区间、全选）：完成/改期/移清单/删除，全部可撤销
- 拖拽：列表行拖到侧栏清单改归属；日历日程行拖到日期格改安排（保留时刻）

**导航与 Mac 体验**
- 统一 212pt 侧栏：任务视图（带计数）、动态清单、笔记文件夹、日历、废纸篓
- 窄窗口（<700pt）详情回退：点击/Return 进入详情，返回保留选中与滚动
- 原生菜单栏：设置 ⌘,、新建任务/笔记、搜索 ⌘K、视图切换 ⌘1–5、标准编辑菜单
- 系统通知：任务提醒到点投递，点击通知直达任务；完成/删除/改期同步撤销登记；设置页显示授权状态
- 菜单栏常驻 + 全局快速录入：⇧⌘Space 呼出非激活录入条，Return 保存到收集箱、Esc 取消，不抢占原应用焦点
- 窗口位置/尺寸记忆；关闭窗口驻留后台、Dock 重开；⌘Q 明确退出
- 外观三态偏好（跟随系统/浅色/深色）持久化；最小窗口 880×600

**笔记**
- 本地笔记支持纯文本编辑；导入的链接/列表等富文本会保留原结构，追加新行可继续写入，改写格式化内容前需明确转换为纯文本副本
- 全文搜索（命令面板覆盖标题/正文/预览）
- 任务—笔记联动：笔记选中文字生成任务（原文不动），任务保留来源笔记并可跳回；笔记侧显示关联任务与完成状态，可勾选
- 附件：任务可选取文件（拷入沙盒容器），芯片管理、Finder 中展示

## 当前限制

- 富文本编辑器尚未接入：当前保留导入原件并提供显式纯文本转换，待真实 Web 笔记样本验证后再选型（如 flutter_quill）
- 全局快捷键目前固定为 ⇧⌘Space，暂不可自定义
- 提醒支持日期＋时间的单点触发；重复任务按完成时间推进链条，并为下一次实例同步提醒
- `flutter analyze`（LSP 分析服务）在本机崩溃，静态检查以 `dart analyze` 为准；分析器仅剩存量 `withOpacity` 弃用提示
- 演示数据会在首次修改后写入本地快照；正式数据请尽早通过“清空本机后导入”覆盖

## 运行与验证

```bash
cd desktop
flutter pub get
flutter run -d macos          # 开发运行
dart analyze                  # 静态检查
flutter test                  # 42 个测试（模型/控制器行为 + 关键 Widget 流程）
flutter build macos --release # 发布构建（已验证可构建、可启动、可退出）
```

## 从 Web 迁移

1. Web 端“设置 → 数据迁移”导出 `.workfollow.json`。
2. macOS 版设置 → 数据 → 选择文件，选择“合并到本机”或“清空本机后导入”。

导入仅包含个人任务、清单、笔记、文件夹（含子任务与来源链接）；团队协同与 Web 附件不在迁移范围内。

## 待实机验收清单

对应方案 §8，以下项目需要在真实 Mac 上人工确认：通知到点投递（含关闭主窗口后）与点击直达、菜单栏全局录入的热键与焦点归还、菜单命令触发、拖拽手感、三种窗口尺寸（1280×800 / 1024×720 / 880×600）下的完整流程、中文输入、VoiceOver 与减少动态效果。

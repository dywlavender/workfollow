# 打勾 macOS 个人版

本地优先的个人任务与笔记应用，位于 `feature/flutter-personal-desktop` 分支。2026-09-13 重做了任务列表、任务编辑、日期选择和笔记工作区，并在此基础上完成一轮整体布局重设计（画布底色上的分组卡片工作台、任务页进度环、笔记卡片列表与编辑器新排版）。交互变化、验证结果和界面截图见[本轮改造说明](../docs/macos-product-rebuild-2026-09-13.md)。

## 日常使用

- 打开应用进入“今天”。首次使用从空任务、空笔记开始；已有本机数据照常载入。
- 在列表上方输入任务，按 Return 添加。宽窗口采用清单 + 常驻详情两栏，点击任务打开文档详情；点击标题或正文进入编辑。中等窗口保留行内展开，窄窗口显示单独编辑页。Esc 先关闭弹出菜单，再退出编辑焦点；行内和窄屏详情再按一次可收起或返回，宽屏详情保留。
- 任务详情采用顶部状态、标题与正文、底部工具三层布局。清单入口在底部；提醒、重复、截止日期、标签等可在“更多”中设置，已设置的提醒与重复显示在顶部。正文空白处可直接点击输入，保存失败时底部提供重试。[本次编辑器改造与截图](../docs/task-editor-redesign-2026-09-16.md)。
- “安排日期”决定什么时候做；“截止日期”表示最晚完成日；“提醒”决定系统通知时间。日期、快捷选项、可选时刻在同一个面板设置，确定后生效，取消不改变原值。
- 改期后任务离开当前视图，会出现去向提示和“查看任务”。已到截止日的任务也会出现在“今天”。
- 已完成默认折叠。支持重复任务、标签、优先级、附件、清单整理、多选批量操作、拖动排序和撤销。
- 子任务视觉基线见 `docs/screenshots/subtask-*.png`（父任务内联列、Child 详情、列表树展开/折叠），由 `test/subtask_shots_test.dart` 在 `--dart-define=WORKFOLLOW_CAPTURE=true` 下生成；全链路同步由 `test/subtask_chain_test.dart` 锁定（创建→命名→列表同步→完成→进入子任务→正文→日期→面包屑返回→折叠展开，全程免刷新）。
- 子任务是一条完整的任务：在父任务详情里"添加子任务"会立即创建空子任务（显示为"无标题"，可直接改名、勾选完成、随日期显示颜色），右侧箭头进入它自己的详情页（带"父任务 ›"面包屑返回），日期必须在子任务详情里设置。任务列表中父任务带折叠箭头，子任务缩进展示并拥有与普通任务一致的整行语法。旧版 checklist 式子任务数据会在加载时自动展开成真实子任务。
- 笔记使用富文本编辑器，支持正文、标题、加粗、斜体、列表、待办列表、引用、代码块、链接和粘贴图片。编辑后自动保存，重新打开保留格式。
- 笔记可以搜索、收藏、归档；侧栏文件夹可以重命名或删除，删除文件夹会把其中笔记移到“未归档”。选中文字可生成带来源链接的任务。
- 设置 → 数据：导入、导出、立即备份、选择备份恢复、打开数据目录。桌面导出文件包含本地附件，可在另一个本地空间恢复。

## macOS 集成

原生菜单、菜单栏快速录入、系统提醒、窗口位置与尺寸记忆、外观偏好、关闭窗口后驻留后台和 Dock 重开均保留。应用图标与应用内“打勾”标识一致。

| 操作 | 快捷键 |
| --- | --- |
| 新任务 | ⌘N |
| 新笔记 | ⇧⌘N |
| 搜索 | ⌘K |
| 设置 | ⌘, |
| 全局快速录入 | ⇧⌘Space |
| 关闭弹层 / 退出编辑焦点 / 收起行内或窄屏详情 | Esc |
| 退出应用 | ⌘Q |

数据保存在应用容器的 Application Support/WorkFollow 中，设置中可以直接打开。每日备份和手动备份保留最近 7 份。恢复前会额外备份当前快照。垃圾桶支持恢复和永久删除。

## 运行与构建

```bash
cd desktop
flutter pub get
flutter run -d macos

dart analyze
flutter test
flutter build macos --release
bash tool/package_macos.sh --skip-build # 校验本地签名并生成应用包
```

产物位于 `build/macos/Build/Products/Release/workfollow_personal.app`。本轮本机打包副本位于 `dist/打勾.app`，压缩包位于 `dist/打勾-macOS.zip`。

需要演示数据时显式开启预览模式；预览快照、附件和外观设置保存在独立的 `preview` 子目录：

```bash
flutter run -d macos --dart-define=WORKFOLLOW_DEMO=true
```

可重复生成本文档中的 Flutter 页面截图：

```bash
flutter test test/product_flow_test.dart --dart-define=WORKFOLLOW_CAPTURE=true
```

截图使用测试空间和本机中文字体，生成到 `docs/screenshots`。它们是实际组件渲染，不等同于原生系统交互验收。

## 数据兼容与范围

原有个人迁移文件可继续导入。桌面富文本同时保存可编辑文档和 Web 可读的内容投影，导入原件另行保留。桌面导出可携带本地附件；历史 Web 附件的下载不在当前迁移流程内。

导入表格当前保留结构并显示，尚不提供表格单元格编辑；普通段落、链接和列表可以直接编辑。全局快速录入热键暂不可自定义。本版本是本机构建，尚未进行 Developer ID 公证和自动更新发布。

当前自动化测试覆盖模型、保存/恢复、任务与笔记交互、智能日期、标签、四象限、周视图、一级入口与第二栏上下文、撤销、窄窗口布局、Popover 几何/翻转/对齐/键盘/外部点击交互以及任务和笔记文档编辑器（富文本、`/` 快捷插入、格式工具、检查项、分割线、附件块、清单搜索、关联笔记）。统计、看板、习惯与番茄专注模块已按需求整体移除（相关持久化字段从快照中省略，旧快照中的这些数据会被安全忽略；四象限保留）。Release 版已复核固定详情栏、任务列表操作、智能清单、原子属性菜单和清爽的快速录入行；中文输入法、系统通知实际投递、全局快捷键、右键菜单和不同尺寸窗口的最终实机结果不能用自动化测试替代。
